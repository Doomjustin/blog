# 提交规范

基于 [Conventional Commits v1.0](https://www.conventionalcommits.org/)。

---

## 格式

```
<type>(<scope>): <subject>

<body>

<footer>
```

---

## Subject 行

- 祈使句，动词原形开头：`add` / `fix` / `remove` / `refactor` …
- 全小写，不加句号
- ≤ 72 字符

---

## Type

| type | 适用场景 |
|------|---------|
| `feat` | 新功能、新公开接口 |
| `fix` | Bug 修复 |
| `test` | 新增或修改测试 |
| `docs` | 文档变更 |
| `refactor` | 重构（无行为变化） |
| `perf` | 性能优化 |
| `chore` | 构建、依赖、CI、配置等杂项 |
| `style` | 格式/空白调整，不影响逻辑 |

---

## Scope

受影响的模块目录名：`common` / `net` / `async` / `examples` / `docs`。  
跨模块改动可省略 scope。

---

## Body（可选，但鼓励）

- 解释**为什么**改，而不是改了什么（diff 已说明 what）
- 每行 ≤ 72 字符，与 subject 之间空一行
- 可用 `-` 列举多条

---

## Footer（可选）

| 用途 | 写法 |
|------|------|
| Breaking change | `BREAKING CHANGE: <description>` |
| subject 速记 | 在 type/scope 后加 `!`，如 `feat(async)!:` |
| 关闭 issue | `Closes #N` |
| 关联 issue | `Refs #N` |

---

## 示例

### 普通 feat

```
feat(net): add async_send_all overload for sequence_buffer
```

### 带 body 的 fix

```
fix(net): handle ECONNRESET in async_read_some

Previously the error was swallowed silently, causing the coroutine to
hang indefinitely on a closed peer connection.

- propagate ECONNRESET as std::errc::connection_reset
- add test case for abrupt client disconnect
```

### 带 body 的 test

```
test(common): add unit tests for hash utilities

Cover use_std_hash, use_fnv_1a, StringHash, and PmrStringHash.

- verify known FNV-1a values for empty string and single byte 'a'
- verify constexpr usability of use_fnv_1a
- verify heterogeneous lookup via unordered_map::contains()
- verify PmrStringHash produces the same value as StringHash
```

### Breaking change

```
feat(async)!: remove IOContext::run() in favor of async::run()

BREAKING CHANGE: IOContext::run() is removed. Call async::run(ctx, task)
instead; this decouples the entry point from the context type.
```
